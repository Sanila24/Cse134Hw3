About the Internship

I worked at IBM as a Software Development Engineer Intern from June through September 2026. My work focused on AI agents and automation tools that supported developer workflows.

These tools connected natural-language requests with technical resources, including command-line interfaces, repository documentation, and Jira tickets.

Coordinating AI Agents

One of my projects was an autonomous bug-fixing pipeline that coordinated eight AI agents using LangGraph to resolve Jira tickets.

Rather than treating a ticket as a single request, the pipeline used multiple agents working together as part of a larger workflow.

Connecting Natural Language With Developer Tools

From Requests to Commands

I built an agent skill that translated natural-language requests into command-line commands. This allowed requests expressed in everyday language to connect with existing developer tools, automating 80% of workflows.

Answering Documentation Questions

I extended the skill to answer natural-language questions using documentation from 12 internal repositories. This brought documentation into the same conversational workflow.

Command-Line Automation

Alongside the agent work, I created new CLI features using Bash scripts to automate developer workflows against a live cloud cluster.

This work connected the AI-focused parts of my internship with the underlying tools used to carry out technical tasks.

Technologies Used

  • LangGraph for coordinating AI agents
  • Jira tickets as inputs to the bug-fixing pipeline
  • Bash scripts and command-line interfaces
  • Documentation from internal repositories
  • A live cloud cluster for developer workflows
