Where Sports and Technology Meet

From July through November 2025, I worked as a Data Science Intern with UCSD Men’s Soccer. As someone who grew up playing and watching soccer, this experience brought together two interests: sports and technology.

My work focused on turning match data into information that could support scouting and performance analysis. This involved collecting data, organizing it, and presenting it through dashboards and reports.

Preparing the Match Data

Before match data could be used in dashboards or reports, it needed to be extracted and prepared. I built Python scripts to collect, clean, and organize data from the Wyscout API.

This work supported scouting for more than 20 opponents.

Making the Data Easier to Understand

I developed Power BI dashboards to visualize pre-game and post-game performance data. Custom DAX queries supported the analysis shown in these dashboards.

The dashboards provided a visual way to explore information that would otherwise remain in raw match data.

From Dashboards to Scouting Reports

I used the dashboard data to build scouting reports. The reporting process reduced preparation time from two hours to under 15 minutes.

The Workflow

  1. Extract match data from the Wyscout API.
  2. Clean and organize the data using Python.
  3. Visualize performance information in Power BI.
  4. Build scouting reports using the dashboard data.

Technologies Used

  • Python for data extraction and preparation
  • Wyscout API for match data
  • Power BI for dashboards and visualizations
  • DAX for custom dashboard queries
